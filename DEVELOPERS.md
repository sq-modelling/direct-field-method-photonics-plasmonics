# Developers and contributors

## Primary software developer

- **Qiang Sun** — primary developer of the Fortran electromagnetic solver and the example-specific drivers in this repository. The original program banners identify “SQ” as the developer.

## Recorded code contribution

- **Evert Klaseboer** — source comments identify the icosahedral sphere-mesh routines as derived from EK's code. The two cube meshes supplied for Fig. 1 are also identified in their file headers as meshes by EK. Legacy source comments identify Evert's code as the basis of some complex linear-solver routines; those legacy solver routines are not part of this trimmed package.
